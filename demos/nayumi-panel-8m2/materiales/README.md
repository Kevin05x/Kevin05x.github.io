# Imágenes de vacantes

Ocho JPG preparados a partir de los PNG originales, conservando su contenido y tamaño de 1254 × 1254. Los originales están en la carpeta de trabajo `marketing/publicaciones` de Kevin.

Las imágenes corresponden a costura Rímac, lencería La Victoria, todo servicio Santa Anita, cocina y limpieza La Molina (Los Frutales), cuidado SJL, cuidado Ate-Mayorazgo, cosmiatría Ate y panadería San Luis. No sustituyen artes de otros puestos con condiciones distintas.

El panel muestra estas imágenes y permite descargarlas. Las versiones nuevas que suba el equipo se guardan con acceso protegido en Cloudflare D1 y tienen prioridad sobre estos archivos. No se copian automáticamente al repositorio: descargarlas desde la ficha para conservar una copia adicional.

El despliegue del Worker también incluye esta carpeta mediante el enlace MATERIALES, con `run_worker_first: true`. La API exige sesión para servir imágenes mediante `/api/vacancy-image/:id`; no publica directamente las nuevas imágenes subidas. Los ocho artes originales ya difundidos están disponibles también como archivos estáticos del repositorio.

Subir o descargar una imagen no publica una vacante en Facebook, Instagram, TikTok, WhatsApp ni Meta Ads.
